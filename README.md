# Horizon Discord RPC

> Broadcast your **Horizon** activity to **Discord** with this lightweight utility.

The tool supports **full customization of all buttons and labels** via the `presence.json` file.

To set up Rich Presence, you need **Python 3.x.x+** and **Windows 10+** to run the `.ps1` scripts. _You are free to port the program to other systems and modify the code as you wish, since the project is released under the The Unlicense._

## Installation

1. Run the `install.ps1` file.
2. When the launcher opens (_or if it is already running_), your Discord activity will display "Horizon" (Playing **Horizon**).
3. Once the game itself starts, your activity will reflect the current state (**singleplayer world** or **server**).
4. Your licensed username will be shown in all activity states (_whether in the launcher menu or in-game_). This feature can be disabled in the **configuration** if desired.
5. Your instances will be displayed as a small icon, **which includes**: the instance icon (_the one you selected when creating it_) and its name shown on hover.
6. To remove the activity, run `uninstall.ps1`.
